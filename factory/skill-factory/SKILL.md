# מפעל הסקילים · The Cyborg

## מתי
כשבונים סקיל חדש למאגר `cyborg-skills`.

## תהליך
1. קרא את `AUTHORING.md` בשורש הריפו: זה ספר החוקים.
2. אסוף מאלעד: נושא, קטגוריה (מתוך 7 הקטגוריות), title_he, רמה, וביטוי הפעלה.
3. הרץ `npm run new-skill name=... category_slug=... category="..." topic="..." title_he="..." level=...`.
4. כתוב את גוף הסקיל בעברית לפי המבנה הקבוע ולפי המתודה המקורית של הסייבורג בלבד.
   לעולם לא לפתוח או להעתיק שיטה חיצונית או חומר של צד שלישי כרפרנס.
5. הרץ `npm run validate` עד שהסקיל ירוק, ואז `npm run build`.
6. הצג לאלעד לאישור. בלי push ובלי deploy בלי אישור מפורש.
