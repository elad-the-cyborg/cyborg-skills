# התקנה · בקרת תוצר לפני מסירה

עובר על תוצר שנוצר בשיחה ומפריד בין מה שנבדק בפועל, מה שנשען על הנחה, ומה שפשוט הומצא

## מה צריך
Claude Code + VS Code. אם עוד אין לך, ראה את מדריך ההתקנה הממותג של הסייבורג.

## התקנה בשורה אחת (העתק והדבק)
```
npx degit elad-the-cyborg/cyborg-skills/skills/00-foundations/output-check ~/.claude/skills/output-check
```

חלופה ידנית: הורד את התיקייה `skills/00-foundations/output-check` וגרור אותה אל
`~/.claude/skills/`.

## איך מפעילים
פתח את קלוד קוד וכתוב: "תעבור על הטקסט הזה לפני שאני מפרסם ותגיד לי מה לא אומת".
