# התקנה · תכנון לפני בנייה

הופך רעיון לתוכנית בת ביצוע לפני שנשרפות שעתיים על בנייה שתפורק, ומסיים בקובץ תוכנית שאפשר לחזור אליו בשיחה הבאה

## מה צריך
Claude Code + VS Code. אם עוד אין לך, ראה את מדריך ההתקנה הממותג של הסייבורג.

## התקנה בשורה אחת (העתק והדבק)
```
npx degit elad-the-cyborg/cyborg-skills/skills/00-foundations/plan-before-build ~/.claude/skills/plan-before-build
```

חלופה ידנית: הורד את התיקייה `skills/00-foundations/plan-before-build` וגרור אותה אל
`~/.claude/skills/`.

## איך מפעילים
פתח את קלוד קוד וכתוב: "אני רוצה לבנות דף נחיתה למוצר החדש, בוא נתכנן קודם".
