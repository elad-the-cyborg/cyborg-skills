# התקנה · בריף קמפיין הסייבורג

סקיל שמראיין אותך בקצרה ובונה בריף קמפיין מסודר בעברית, כדי שכל מודעה או קריאייטיב שתפיק אחר כך יתחיל ממקום ברור.

## מה צריך
Claude Code + VS Code. אם עוד אין לך, ראה את מדריך ההתקנה הממותג של הסייבורג.

## התקנה בשורה אחת (העתק והדבק)
```
npx degit elad-the-cyborg/cyborg-skills/skills/01-research-strategy/campaign-brief ~/.claude/skills/campaign-brief
```

חלופה ידנית: הורד את התיקייה `skills/01-research-strategy/campaign-brief` וגרור אותה אל
`~/.claude/skills/`.

## איך מפעילים
פתח את קלוד קוד וכתוב: "בוא נבנה בריף לקמפיין הבא שלי".
