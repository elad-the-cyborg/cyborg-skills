# התקנה · מכ״ם מתחרים הסייבורג

סוקר עד חמישה מתחרים ומחזיר מה כל אחד מבטיח, איך הוא מתמחר את עצמו, ומה לשנות כדי לבלוט מולו

## מה צריך
Claude Code + VS Code. אם עוד אין לך, ראה את מדריך ההתקנה הממותג של הסייבורג.

## התקנה בשורה אחת (העתק והדבק)
```
npx degit elad-the-cyborg/cyborg-skills/skills/01-research-strategy/competitor-radar ~/.claude/skills/competitor-radar
```

חלופה ידנית: הורד את התיקייה `skills/01-research-strategy/competitor-radar` וגרור אותה אל
`~/.claude/skills/`.

## איך מפעילים
פתח את קלוד קוד וכתוב: "תבדוק לי את המתחרים שלי בתחום".

## מה הסקיל עושה בפועל
הסקיל לא כותב ולא משנה שום קובץ במחשב שלך, כל התוצר מוצג בשיחה. כדי לבדוק מתחרים
הוא כן פותח כתובות אינטרנט (אתרי מתחרים, ולפעמים ספריית המודעות הציבורית של מטא)
אם יש לו גישה לכלי כזה. אם אין, הוא יבקש ממך לינק או טקסט במקום לנחש.
