# התקנה · בודק הנראות של הסייבורג

בודק אתר עסק גם מול חיפוש רגיל בגוגל וגם מול הדרך שבינה מלאכותית עונה לשאלות

## מה צריך
Claude Code מותקן על המחשב, וזה חינם, ואם נוח לך גם VS Code. אם עוד אין לך
Claude Code, ההתקנה לוקחת כמה דקות לפי ההוראות הרשמיות של Anthropic, ואפשר
לעבוד גם מהטרמינל וגם מתוך VS Code.

## התקנה בשורה אחת (העתק והדבק)
```
npx degit elad-the-cyborg/cyborg-skills/skills/01-research-strategy/findability-audit ~/.claude/skills/findability-audit
```

חלופה ידנית: הורד את התיקייה `skills/01-research-strategy/findability-audit` וגרור אותה אל
`~/.claude/skills/`.

## איך מפעילים
פתח את קלוד קוד וכתוב: "תבדוק לי אם האתר שלי נמצא בגוגל ובבינה מלאכותית".

## מה הסקיל עושה בפועל
הסקיל לא כותב ולא משנה שום קובץ במחשב שלך, כל התוצר מוצג בשיחה. הוא כן פותח את
האתר שלך (עמוד הבית ועוד כמה עמודים) כדי לבדוק אותו, אם יש לו גישה לכלי גלישה. אם
אין, הוא יבקש ממך להדביק את התוכן במקום לנחש איך האתר נראה.
