# התקנה · בודק הנראות של הסייבורג

בודק אתר עסק גם מול חיפוש רגיל בגוגל וגם מול הדרך שמנועי תשובות עונים לשאלות

## מה צריך
Claude Code מותקן על המחשב, וזה חינם, ואם נוח לך גם VS Code. אם עוד אין לך
Claude Code, ההתקנה לוקחת כמה דקות לפי ההוראות הרשמיות של Anthropic, ואפשר
לעבוד גם מהטרמינל וגם מתוך VS Code.

## התקנה בשורה אחת (העתק והדבק)
```
npx degit elad-the-cyborg/cyborg-skills/skills/01-research-strategy/findability-audit ~/.claude/skills/findability-audit
```

חלופה ידנית: הורד את התיקייה `skills/01-research-strategy/findability-audit` וגרור אותה אל
`~/.claude/skills/`.

## איך מפעילים
פתח את קלוד קוד וכתוב: "תבדוק לי אם האתר שלי נמצא בגוגל ובבינה מלאכותית".

## מה יש בפנים
בתוך תיקיית הסקיל יש תיקייה בשם `references` עם שכבת המקצוע, שנקראת רק בשלב שדורש
אותה: `aeo-geo-method.md` (איך בודקים בפועל אם מנוע תשובות מכיר את העסק, ומה גורם לו
לצטט מקור אחד ולא אחר), ו-`report-format.md` (איך נראה דוח שבעל עסק באמת מבצע).
`hebrew-human-writing.md` הוא קובץ משותף לכמה סקילים במאגר, והוא מגיע יחד עם הסקיל.

## מה הסקיל עושה בפועל
הוא פותח את האתר שלך (עמוד הבית ועוד כמה עמודים) כדי לבדוק אותו, אם יש לו גישה לכלי
גלישה, ואם אין הוא יבקש ממך להדביק את התוכן במקום לנחש איך האתר נראה.

בסוף הבדיקה הוא מציע לשמור קובץ זיכרון אחד ב-`~/.claude/cyborg-memory/findability-audit.md`
עם כתובת האתר, שאלות הבדיקה והממצאים, כדי שהבדיקה הבאה תמדוד מה תוקן. הקובץ נשמר רק
אחרי שהוא מציג לך בדיוק מה עומד להישמר ואתה מאשר, בלי סיסמאות ובלי פרטי גישה, ואפשר
לערוך או למחוק אותו מתי שרוצים. חוץ מהקובץ הזה הסקיל לא כותב ולא משנה שום דבר במחשב.
