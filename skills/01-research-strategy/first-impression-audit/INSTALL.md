# התקנה · בודק הרושם הראשוני הסייבורג

בודק את דף הבית מנקודת המבט של מבקר חדש ומאתר איפה הרושם הראשוני נופל

## מה צריך
Claude Code + VS Code. אם עוד אין לך, ראה את מדריך ההתקנה הממותג של הסייבורג.

## התקנה בשורה אחת (העתק והדבק)
```
npx degit elad-the-cyborg/cyborg-skills/skills/01-research-strategy/first-impression-audit ~/.claude/skills/first-impression-audit
```

חלופה ידנית: הורד את התיקייה `skills/01-research-strategy/first-impression-audit` וגרור אותה אל
`~/.claude/skills/`.

## איך מפעילים
פתח את קלוד קוד וכתוב: "תבדוק לי את הרושם הראשוני שהאתר שלי יוצר".

## מה הסקיל עושה בפועל
הסקיל לא כותב ולא משנה שום קובץ במחשב שלך, כל התוצר מוצג בשיחה. הקלט הכי מדויק
הוא צילום מסך שאתה מדביק בעצמך. אם אין צילום מסך, הוא יפתח את כתובת האתר שנתת
לו כדי לקרוא את הטקסט והמבנה שלו, אבל יגיד לך בפירוש שזו בדיקה חלקית בלי תמונה.
