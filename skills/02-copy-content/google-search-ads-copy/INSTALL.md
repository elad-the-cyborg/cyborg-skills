# התקנה · קופי למודעות חיפוש בגוגל

מייצר כותרות ותיאורים למודעת חיפוש בגוגל בתוך מגבלת התווים המדויקת, לפי כוונת החיפוש

## מה צריך
Claude Code + VS Code. אם עוד אין לך, ראה את מדריך ההתקנה הממותג של הסייבורג.

## התקנה בשורה אחת (העתק והדבק)
```
npx degit elad-the-cyborg/cyborg-skills/skills/02-copy-content/google-search-ads-copy ~/.claude/skills/google-search-ads-copy
```

חלופה ידנית: הורד את התיקייה `skills/02-copy-content/google-search-ads-copy` וגרור אותה אל
`~/.claude/skills/`.

## איך מפעילים
פתח את קלוד קוד וכתוב: "תכתוב לי מודעת חיפוש בגוגל על [המוצר שלי]".
