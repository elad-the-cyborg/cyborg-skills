# התקנה · מלטש העברית של הסייבורג

מקבל טקסט בעברית ומחזיר אותו בניסוח ישראלי טבעי, מראה לפני ואחרי על אותם משפטים,
ובסוף נותן שורת הנחיה אחת קבועה להמשך. את הסגנון שלך הוא לומד פעם אחת וזוכר.

## מה צריך
Claude Code מותקן על המחשב, וזה חינם, ואם נוח לך גם VS Code. אם עוד אין לך
Claude Code, ההתקנה לוקחת כמה דקות לפי ההוראות הרשמיות של Anthropic, ואפשר
לעבוד גם מהטרמינל וגם מתוך VS Code.

## התקנה בשורה אחת (העתק והדבק)
```
npx degit elad-the-cyborg/cyborg-skills/skills/02-copy-content/hebrew-copy-refiner ~/.claude/skills/hebrew-copy-refiner
```

חלופה ידנית: הורד את התיקייה `skills/02-copy-content/hebrew-copy-refiner` וגרור אותה אל
`~/.claude/skills/`.

## איך מפעילים
פתח את קלוד קוד וכתוב: "תנקה לי את הטקסט הזה שיישמע כמו עברית שלי", ותדביק את הטקסט
מתחת.

רוצה שהתוצאה תישמע כמוך ולא רק "טבעית"? תדביק גם טקסט ישן משלך שאהבת איך הוא יצא,
באורך של 150 מילים לפחות (מ-300 מילים המדידה כבר אמינה). הסקיל מודד ממנו שישה דברים,
בהם אורך המשפט, גוף הפנייה, רמת הרשמיות והביטויים שחוזרים אצלך, ומחיל אותם על הטקסט
החדש.

## מה מקבלים בסוף
שלושה דברים: את הטקסט הנקי בבלוק אחד להעתקה, לפני ואחרי שמראה מה השתנה ולמה, ושורת
הנחיה אחת מותאמת לסגנון שלך. את השורה הזו אפשר להדביק בסוף כל בקשה עתידית לקלוד, בכל
שיחה, ולקבל את אותה עברית בלי להריץ את הסקיל שוב.

## מה הסקיל שומר אצלך
קובץ אחד: `~/.claude/cyborg-memory/hebrew-copy-refiner.md`. בתוכו כרטיס הסגנון שלך
ושורת ההנחיה שנבנתה לך, כדי שבפעם הבאה לא תצטרך ללמד אותו מחדש. הוא נשמר רק אחרי
שהסקיל מראה לך בדיוק מה נכנס פנימה ואתה מאשר, הטקסטים עצמם לא נשמרים בו, ואפשר לפתוח,
לערוך או למחוק את הקובץ בכל רגע. מחיקה שלו מוחקת את הזיכרון.

חוץ מהקובץ הזה הסקיל לא נוגע בשום קובץ שלך, לא יוצא לרשת ולא מוציא שום דבר החוצה.

## מה יש בתיקייה
- `SKILL.md` · מהלך העבודה עצמו.
- `references/style-learning.md` · איך לומדים סגנון מדוגמה: כמה טקסט צריך כדי שהמדידה
  תהיה אמינה, שישה מדדים שסופרים, ואיך המדידה הופכת לשורת ההנחיה הקבועה.
- `references/hebrew-human-writing.md` · כללי העברית האנושית, משותפים לכל הסקילים.

חשוב לקחת את התיקייה כולה ולא רק את הקובץ `SKILL.md`. בלי תיקיית `references` ההפניות
שבתוך הסקיל לא ימצאו לאן ללכת, והוא יעבוד חלקית בלבד.

## עברית בקרוסלה או בבאנר
הסקיל הזה מטפל בטקסט, לא בעיצוב. אם האותיות בעברית יוצאות הפוך או מפוזרות בתוך
תמונה, זו בעיה אחרת לגמרי, ומטפל בה הסקיל `instagram-carousel`.
