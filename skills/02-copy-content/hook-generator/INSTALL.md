# התקנה · מחולל ההוקים של הסייבורג

מקבל את המוצר והקהל שלך, ומחזיר 10 הוקים בזוויות שונות ושלושה מובילים.

## מה צריך
Claude Code מותקן על המחשב, וזה חינם, ואם נוח לך גם VS Code. אם עוד אין לך
Claude Code, ההתקנה לוקחת כמה דקות לפי ההוראות הרשמיות של Anthropic, ואפשר
לעבוד גם מהטרמינל וגם מתוך VS Code.

## התקנה בשורה אחת (העתק והדבק)
```
npx degit elad-the-cyborg/cyborg-skills/skills/02-copy-content/hook-generator ~/.claude/skills/hook-generator
```

חלופה ידנית: הורד את התיקייה `skills/02-copy-content/hook-generator` וגרור אותה אל
`~/.claude/skills/`.

## איך מפעילים
פתח את קלוד קוד וכתוב: "תן לי הוקים למודעה על [המוצר שלך]".

## מה הסקיל יוצר
כלום. הסקיל לא כותב ולא משנה שום קובץ, הוא רק עונה בשיחה עם ההוקים המוצעים.
