# התקנה · קופי לדף נחיתה

בונה מבנה וקופי לדף נחיתה לפי שאלות המבקר בזמן אמת, לא לפי תבנית קבועה של סעיפים

## מה צריך
Claude Code + VS Code. אם עוד אין לך, ראה את מדריך ההתקנה הממותג של הסייבורג.

## התקנה בשורה אחת (העתק והדבק)
```
npx degit elad-the-cyborg/cyborg-skills/skills/02-copy-content/landing-page-copy ~/.claude/skills/landing-page-copy
```

חלופה ידנית: הורד את התיקייה `skills/02-copy-content/landing-page-copy` וגרור אותה אל
`~/.claude/skills/`.

## איך מפעילים
פתח את קלוד קוד וכתוב: "תבנה לי קופי לדף נחיתה על [המוצר או השירות שלי]".
