# התקנה · קופי למודעות מטא

מייצר כמה גרסאות קופי למודעת פייסבוק ואינסטגרם, מותאמות לפיד ולגלילה בנייד

## מה צריך
Claude Code מותקן על המחשב, וזה חינם, ואם נוח לך גם VS Code. אם עוד אין לך
Claude Code, ההתקנה לוקחת כמה דקות לפי ההוראות הרשמיות של Anthropic, ואפשר
לעבוד גם מהטרמינל וגם מתוך VS Code.

## התקנה בשורה אחת (העתק והדבק)
```
npx degit elad-the-cyborg/cyborg-skills/skills/02-copy-content/meta-ads-copy ~/.claude/skills/meta-ads-copy
```

חלופה ידנית: הורד את התיקייה `skills/02-copy-content/meta-ads-copy` וגרור אותה אל
`~/.claude/skills/`.

## איך מפעילים
פתח את קלוד קוד וכתוב: "תכתוב לי קופי למודעת מטא על [המוצר שלי]".
