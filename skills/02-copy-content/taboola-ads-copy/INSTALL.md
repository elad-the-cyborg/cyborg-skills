# התקנה · קופי למודעות טאבולה

מייצר כותרות ותמונות מוצעות למודעת טאבולה שמעוררות סקרנות אמיתית בלי קליקבייט

## מה צריך
Claude Code + VS Code. אם עוד אין לך, ראה את מדריך ההתקנה הממותג של הסייבורג.

## התקנה בשורה אחת (העתק והדבק)
```
npx degit elad-the-cyborg/cyborg-skills/skills/02-copy-content/taboola-ads-copy ~/.claude/skills/taboola-ads-copy
```

חלופה ידנית: הורד את התיקייה `skills/02-copy-content/taboola-ads-copy` וגרור אותה אל
`~/.claude/skills/`.

## איך מפעילים
פתח את קלוד קוד וכתוב: "תכתוב לי כותרות טאבולה למאמר על [הנושא שלי]".
