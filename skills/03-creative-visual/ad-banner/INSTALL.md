# התקנה · הפקת באנרים

מפיק מודעות תמונה עם עברית תקינה, בשיטה שמייצרת את הסצנה בלי טקסט ומלבישה את הכיתוב עליה בשלב נפרד

## מה צריך
Claude Code + VS Code. אם עוד אין לך, ראה את מדריך ההתקנה הממותג של הסייבורג.

## התקנה בשורה אחת (העתק והדבק)
```
npx degit elad-the-cyborg/cyborg-skills/skills/03-creative-visual/ad-banner ~/.claude/skills/ad-banner
```

חלופה ידנית: הורד את התיקייה `skills/03-creative-visual/ad-banner` וגרור אותה אל
`~/.claude/skills/`.

## איך מפעילים
פתח את קלוד קוד וכתוב: "תפיק לי באנר לפיד ולסטורי לפי הקופי שאישרתי".
