# התקנה · פלטת מותג הסייבורג

סקיל שבונה פלטת צבעים וטיפוגרפיה עקבית למותג שלך, כולל תצוגה חזותית שאפשר לפתוח בדפדפן ולראות איך זה נראה באמת.

## מה צריך
Claude Code + VS Code. אם עוד אין לך, ראה את מדריך ההתקנה הממותג של הסייבורג.

## התקנה בשורה אחת (העתק והדבק)
```
npx degit elad-the-cyborg/cyborg-skills/skills/03-creative-visual/brand-palette ~/.claude/skills/brand-palette
```

חלופה ידנית: הורד את התיקייה `skills/03-creative-visual/brand-palette` וגרור אותה אל
`~/.claude/skills/`.

## איך מפעילים
פתח את קלוד קוד וכתוב: "בנה לי פלטת מותג".

## מה הסקיל יוצר
הסקיל כותב קובץ `palette-preview.html` ומציע לפתוח אותו בדפדפן כדי לראות את הפלטה בפועל. פתיחת התצוגה משתמשת בדפדפן שמותקן על המחשב שלך. בסיום, הוא עשוי להציע להוסיף את טוקני הצבע לקובץ ה-`CLAUDE.md` הקיים שלך, ורק אחרי אישור מפורש ממך.
