# התקנה · פלטת מותג

בונה פלטת צבעים וזוג גופנים לעסק, מאמת שהטקסט באמת קריא על הרקע, ומייצר תצוגה שאפשר לפתוח בדפדפן ולראות

## מה צריך
Claude Code + VS Code. אם עוד אין לך, ראה את מדריך ההתקנה הממותג של הסייבורג.

## התקנה בשורה אחת (העתק והדבק)
```
npx degit elad-the-cyborg/cyborg-skills/skills/03-creative-visual/brand-palette ~/.claude/skills/brand-palette
```

חלופה ידנית: הורד את התיקייה `skills/03-creative-visual/brand-palette` וגרור אותה אל
`~/.claude/skills/`.

## איך מפעילים
פתח את קלוד קוד וכתוב: "תבנה לי פלטת צבעים למותג ותראה לי איך זה נראה".
