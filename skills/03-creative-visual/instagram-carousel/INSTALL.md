# התקנה · בניית קרוסלה לאינסטגרם

בונה קרוסלה שלמה לאינסטגרם, מרעיון ועד קבצי תמונה מוכנים להעלאה, עם עברית ימין לשמאל תקינה בכל שקף

## מה צריך
Claude Code + VS Code. אם עוד אין לך, ראה את מדריך ההתקנה הממותג של הסייבורג.

בנוסף, הסקיל מצלם כל שקף מקובץ HTML לתמונה דרך Google Chrome (במצב ללא חלון
גלוי), כדי שהעברית תיקרא נכון מימין לשמאל. אם Chrome כבר מותקן על המחשב שלך
אין מה לעשות, הסקיל בודק את זה לבד. אם לא, תתבקש להתקין אותו כאפליקציה רגילה
מ-google.com/chrome (בלי סיסמת מנהל, בדיוק כמו כל אפליקציה אחרת).

## התקנה בשורה אחת (העתק והדבק)
```
npx degit elad-the-cyborg/cyborg-skills/skills/03-creative-visual/instagram-carousel ~/.claude/skills/instagram-carousel
```

חלופה ידנית: הורד את התיקייה `skills/03-creative-visual/instagram-carousel` וגרור אותה אל
`~/.claude/skills/`.

## איך מפעילים
פתח את קלוד קוד וכתוב: "תבנה לי קרוסלה לאינסטגרם על המוצר שלי".
