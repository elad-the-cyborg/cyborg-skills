# התקנה · בניית קרוסלה לאינסטגרם

בונה קרוסלה שלמה לאינסטגרם, מרעיון ועד קבצי תמונה מוכנים להעלאה, עם עברית ימין לשמאל תקינה בכל שקף

## מה צריך
Claude Code מותקן על המחשב, וזה חינם, ואם נוח לך גם VS Code. אם עוד אין לך
Claude Code, ההתקנה לוקחת כמה דקות לפי ההוראות הרשמיות של Anthropic, ואפשר
לעבוד גם מהטרמינל וגם מתוך VS Code.

בנוסף, הסקיל מצלם כל שקף מקובץ HTML לתמונה דרך Google Chrome (במצב ללא חלון
גלוי), כדי שהעברית תיקרא נכון מימין לשמאל. אם Chrome כבר מותקן על המחשב שלך
אין מה לעשות, הסקיל בודק את זה לבד. אם לא, תתבקש להתקין אותו כאפליקציה רגילה
מ-google.com/chrome (בלי סיסמת מנהל, בדיוק כמו כל אפליקציה אחרת).

הפקודות בסקיל כתובות לנתיב של Chrome במק. אם אתה עובד על ווינדוס או לינוקס,
הרעיון זהה אבל הנתיב שונה, ושווה לומר את זה לקלוד בתחילת השיחה.

## מה הסקיל עושה בפועל
הסקיל כותב קבצים חדשים במחשב שלך: קובץ HTML לכל שקף וקובץ תמונה PNG לכל שקף,
בתיקייה חדשה שנוצרת לפי הנושא והתאריך. הוא לא דורס תיקייה קיימת ולא מוחק כלום.
הוא לא מתחבר לאינטרנט, ולא מעלה שום דבר לאינסטגרם. ההעלאה בפועל נשארת אצלך.
