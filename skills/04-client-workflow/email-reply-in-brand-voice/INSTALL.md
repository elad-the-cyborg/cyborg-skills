# התקנה · מחולל מענה למיילים בטון המותג

טיוטת תשובה מסודרת בעברית לכל מייל נכנס, בטון של העסק שלך, במקום עשרים דקות מול מסך ריק.

## מה צריך
Claude Code מותקן על המחשב, וזה חינם, ואם נוח לך גם VS Code. מומלץ שכבר יהיה לך
קובץ CLAUDE.md מוגדר לעסק שלך (הסקיל `brand-voice-setup` מייצר אותו בשיחה של שש
שאלות), כי ממנו הסקיל לוקח את הטון. חיבור לגמייל הוא רשות ולא חובה: בלעדיו פשוט
מדביקים את המייל בשיחה.

## התקנה בשורה אחת (העתק והדבק)
```
npx degit elad-the-cyborg/cyborg-skills/skills/04-client-workflow/email-reply-in-brand-voice ~/.claude/skills/email-reply-in-brand-voice
```

חלופה ידנית: הורד את התיקייה `skills/04-client-workflow/email-reply-in-brand-voice`
וגרור אותה אל `~/.claude/skills/`.

## איך מפעילים
פתח את קלוד קוד וכתוב: "תכין לי טיוטת תשובה למייל הזה", והדבק את המייל.

## מה הסקיל עושה בפועל
הסקיל קורא את קובץ CLAUDE.md שלך ואת המייל הנכנס, מסמן את כל השאלות ודרישות הפעולה
שבו, שואל אותך שאלה או שתיים אם חסר לו כיוון, ומרכיב טיוטה שמתייחסת לכל נקודה לפי
הסדר. הטיוטה מוצגת לך בשיחה, ואפשר לתקן טון או ניסוח לפני שממשיכים.

**הסקיל לא שולח מיילים, אף פעם.** אחרי שאתה מאשר את הנוסח הוא מציע לשמור אותו
כטיוטה בגמייל (רק אם חיברת), או להחזיר לך את הטקסט להעתקה. הלחיצה על שליחה תמיד
שלך, מהגמייל, אחרי קריאה אחרונה.
