# התקנה · תיק ההכנה לפגישה של הסייבורג

תיק הכנה של דף אחד לפני פגישה: מה החברה עושה, שלוש נקודות שראוי להזכיר, שני סיכונים, וחמש שאלות פתיחה מוכנות.

## מה צריך
Claude Code מותקן על המחשב, וזה חינם, ואם נוח לך גם VS Code. הסקיל עובד עם או בלי
קובץ CLAUDE.md מוגדר לעסק שלך, אבל עם קובץ הוא יזהה טוב יותר סיכונים והזדמנויות
שרלוונטיים דווקא לתחום שלך.

## התקנה בשורה אחת (העתק והדבק)
```
npx degit elad-the-cyborg/cyborg-skills/skills/04-client-workflow/pre-meeting-prep ~/.claude/skills/pre-meeting-prep
```

חלופה ידנית: הורד את התיקייה `skills/04-client-workflow/pre-meeting-prep` וגרור
אותה אל `~/.claude/skills/`.

## איך מפעילים
פתח את קלוד קוד וכתוב: "תכין לי תיק הכנה לפגישה עם [שם חברה] מחר".

## מה הסקיל עושה בפועל
הסקיל שואל שם החברה, איש הקשר ומטרת הפגישה. אחר כך הוא סורק את האתר של החברה
ומידע ציבורי זמין (חדשות, לינקדאין), ומחזיר תיק של דף אחד: מה החברה עושה, שלוש
נקודות שראוי להזכיר, שני סיכונים אפשריים, וחמש שאלות פתיחה קונקרטיות.

הסקיל לא ניגש למידע אישי של איש הקשר (משפחה, כתובת, היסטוריה אישית), גם אם ניתן
למצוא ברשת, ולא כותב אליו מיילים או הודעות ישירות בשמך.
