# התקנה · הרוטינה היומית של הסייבורג

מריץ את יום העבודה בחמש תחנות קבועות, מהבוקר ועד הסגירה, ומחבר בין הסקילים שכבר מותקנים אצלך.

## מה צריך
Claude Code מותקן על המחשב, וזה חינם, ואם נוח לך גם VS Code.

הרוטינה עצמה עובדת מיד אחרי ההתקנה, אבל היא מנצחת על סקילים אחרים, אז ככל שיותר
מהם מותקנים כך יותר תחנות ייפתחו. חמש התחנות נשענות על הסקילים האלה:

```
gmail-invoice-sync     ->  skills/05-operations/gmail-invoice-sync
meta-ads-reader        ->  skills/05-operations/meta-ads-reader
price-quote-generator  ->  skills/04-client-workflow/price-quote-generator
competitor-radar       ->  skills/01-research-strategy/competitor-radar
pre-meeting-prep       ->  skills/04-client-workflow/pre-meeting-prep
```

אין חובה להתקין את כולם לפני שמתחילים. תחנה שהסקיל שלה חסר פשוט מדולגת, והרוטינה
אומרת לך בדיוק מה להתקין כדי לפתוח אותה.

## התקנה בשורה אחת (העתק והדבק)
```
npx degit elad-the-cyborg/cyborg-skills/skills/05-operations/daily-cyborg-routine ~/.claude/skills/daily-cyborg-routine
```

חלופה ידנית: הורד את התיקייה `skills/05-operations/daily-cyborg-routine` וגרור אותה
אל `~/.claude/skills/`.

## איך מפעילים
פתח את קלוד קוד וכתוב: "בוא נתחיל את יום העבודה".

בסוף היום אפשר לפתוח שוב ולכתוב: "בוא נסכם את היום ונתכנן את מחר".

## מה הסקיל עושה בפועל
הסקיל בודק אילו מהסקילים של התחנות מותקנים אצלך, מציג את חמש התחנות עם הזמן המשוער
לכל אחת, ושואל אילו מהן רלוונטיות ליום הזה. אתה בוחר, והוא מריץ רק את מה שבחרת:
סיכום בוקר של מיילים, חשבוניות וקמפיינים, הפקת הצעת מחיר, סקירת מתחרים, תיק הכנה
לפגישה, ומעבר אחרון על חשבוניות בערב. אחרי כל תחנה הוא עוצר ושואל אם להמשיך, כך
שהיום לא רץ מהתחלה ועד הסוף בלי שאתה בתמונה. בסוף הוא מציג סיכום אחד: מה נעשה, מה
נשאר פתוח, ושלוש המשימות הראשונות למחר.

הסקיל עצמו לא שולח מייל, הודעה או פרסום בשמך, לא נוגע בקמפיינים חיים, ולא מייצר את
התוצרים לבד. מה שכן יוצא מהמחשב הוא קריאת נתונים מתיבת המייל ומחשבון המודעות,
בתוך הסקילים שהתחנות מזמנות. כל תוצר יוצא מהסקיל הייעודי שלו, עם כללי האישור שלו. הקובץ היחיד
שהרוטינה שומרת הוא יומן יום מקומי בתיקיית העבודה, ורק אחרי שאתה מאשר.
