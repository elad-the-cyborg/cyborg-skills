# התקנה · סנכרון חשבוניות מהמייל של הסייבורג

סריקה של תיבת הגמייל שמזהה חשבוניות וקבלות מספקים, מחלצת סכום ותאריך, ומתייקת בגוגל דרייב לפי חודש.

## מה צריך
Claude Code מותקן על המחשב, וזה חינם. חייבים חיבור פעיל של קלוד קוד לחשבון גמייל
של העסק ולגוגל דרייב שלו. מוסיפים אותם בתוך קלוד קוד עם הפקודה `/mcp`, או מהטרמינל
עם `claude mcp add`.

## התקנה בשורה אחת (העתק והדבק)
```
npx degit elad-the-cyborg/cyborg-skills/skills/05-operations/gmail-invoice-sync ~/.claude/skills/gmail-invoice-sync
```

חלופה ידנית: הורד את התיקייה `skills/05-operations/gmail-invoice-sync` וגרור אותה
אל `~/.claude/skills/`.

## איך מפעילים
פתח את קלוד קוד וכתוב: "סרוק את הגמייל ותייק חשבוניות מהחודש האחרון בדרייב".

## מה הסקיל עושה בפועל
הסקיל שואל טווח תאריכים ותיקת יעד בדרייב, סורק את הגמייל לפי מילות מפתח (חשבונית,
קבלה, invoice, receipt), מזהה קבצים מצורפים שהם באמת מסמכי חשבונאות, מחלץ סכום
ותאריך ושם ספק, ומציג לך רשימה בשיחה. רק אחרי שאתה מאשר את הרשימה, הסקיל מתייק
את הקבצים בגוגל דרייב לפי חודש עם שמות קבצים מסודרים.

הסקיל לא מוחק ולא מזיז מיילים בגמייל, לא מזין נתונים למערכת הנהלת חשבונות, ולא
שולח מיילים אוטומטית בשמך. הצעת שליחה של סיכום לרואה החשבון מוצגת רק אחרי אישור
מפורש.
