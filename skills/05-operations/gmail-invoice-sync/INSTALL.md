# התקנה · סנכרון חשבוניות מהמייל של הסייבורג

סריקה של תיבת המייל שמזהה אילו מיילים באמת מחזיקים מסמך חשבונאי, מסמנת את מה שנופל בין
הכיסאות, ומתייקת בגוגל דרייב לפי שנה וחודש.

## מה צריך
Claude Code מותקן על המחשב, וזה חינם. חייבים חיבור פעיל של קלוד קוד לחשבון הגמייל של
העסק ולגוגל דרייב שלו. מוסיפים אותם בתוך קלוד קוד עם הפקודה `/mcp`, או מהטרמינל עם
`claude mcp add`.

## התקנה בשורה אחת (העתק והדבק)
```
npx degit elad-the-cyborg/cyborg-skills/skills/05-operations/gmail-invoice-sync ~/.claude/skills/gmail-invoice-sync
```

חלופה ידנית: הורד את התיקייה `skills/05-operations/gmail-invoice-sync` וגרור אותה
אל `~/.claude/skills/`.

## איך מפעילים
פתח את קלוד קוד וכתוב: "סרוק את הגמייל ותייק חשבוניות מהחודש האחרון בדרייב".

## מה הסקיל עושה בפועל
הסקיל שואל טווח תאריכים ותיקת יעד, סורק את הגמייל, ואז מעביר כל תוצאה דרך שיטת הזיהוי
שלו: מייל שיווקי שכתובה בו המילה חשבונית יוצא מהרשימה, ומסמך אמיתי מסווג לסוג שלו
(חשבונית מס, קבלה, חשבונית מס קבלה, זיכוי), כי רואה החשבון צריך את הסוג הנכון.

הוא גם מסמן בנפרד את המקרים שבהם נוצרים החורים בתיק: חשבונית שיושבת רק בקישור להורדה,
חשבונית שכתובה בגוף המייל בלי קובץ, חיוב במטבע זר, וזיכוי. ואם ספק קבוע לא הגיעה ממנו
חשבונית החודש, הוא אומר את זה במפורש.

לפני שהוא נוגע בקובץ אחד, הסקיל מציג טבלה של כל מה שנמצא ומחכה לאישור. רק אחרי אישור
הוא מתייק בדרייב לפי שנה וחודש, בשם קובץ אחיד שאפשר למצוא לפיו גם בעוד שנה.

## מה הסקיל כותב, ומה הוא לא עושה
הסקיל מעלה את המסמכים שאישרת לתיקייה שלך בגוגל דרייב, וזו הפעולה היחידה שלו שיוצאת
החוצה. בנוסף, אם תאשר, הוא שומר קובץ זיכרון מקומי אחד ב-
`~/.claude/cyborg-memory/gmail-invoice-sync.md` עם מבנה התיקיות שבחרת, מוסכמת השמות,
הספקים הקבועים שזוהו והספקים שביקשת לדלג עליהם. בקובץ הזה לא נשמרים סכומים, מספרי
מסמכים או פרטי חשבון, ואפשר לפתוח או למחוק אותו מתי שרוצים.

הסקיל לא מוחק ולא מזיז מיילים בגמייל, לא מוריד קבצים מקישורים חיצוניים ולא נכנס לממשקי
חיוב של ספקים, לא מזין נתונים למערכת הנהלת חשבונות, ולא מעביר שום דבר לרואה החשבון.
הסיכום נשאר אצלך.

## מה יש בתיקייה
- `SKILL.md` · מהלך העבודה עצמו.
- `references/invoice-method.md` · שיטת הזיהוי והתיוק: סוגי המסמכים וההבדל ביניהם, סימני
  הזיהוי, המקרים שנופלים בין הכיסאות, ומבנה התיקיות ומוסכמת השמות בדרייב.
- `references/hebrew-human-writing.md` · כללי העברית האנושית, משותפים לכל הסקילים.

חשוב לקחת את התיקייה כולה ולא רק את הקובץ `SKILL.md`. בלי תיקיית `references` ההפניות
שבתוך הסקיל לא ימצאו לאן ללכת, והוא יעבוד חלקית בלבד.
