# התקנה · קורא הקמפיינים של הסייבורג

שואלים בעברית איך רץ הקמפיין במטא, ומקבלים שורה אחת עם ההוצאה, מספר הלידים והעלות
לליד. חיבור צפייה בלבד.

## מה צריך
Claude Code מותקן על המחשב, וזה חינם. בנוסף צריך חיבור פעיל של קלוד קוד לחשבון
המודעות שלך במטא. מוסיפים אותו בתוך קלוד קוד עם הפקודה `/mcp`, או מהטרמינל עם
`claude mcp add`.

שווה לדעת מראש: החיבור הרשמי של מטא מגיע עם סט כלים מלא, ואין בו מסך שבו בוחרים
"קריאה בלבד". הסקיל הזה קורא נתונים ולא קורא לאף כלי שמשנה קמפיין, וקלוד קוד עוצר
ושואל לפני כל פעולה שמשנה משהו. מי שרוצה חסימה קשיחה יכול לבקש מקלוד לחסום את כלי
הכתיבה של מטא בהגדרות, ולהשאיר רק קריאה.

## התקנה בשורה אחת (העתק והדבק)
```
npx degit elad-the-cyborg/cyborg-skills/skills/05-operations/meta-ads-reader ~/.claude/skills/meta-ads-reader
```

חלופה ידנית: הורד את התיקייה `skills/05-operations/meta-ads-reader` וגרור אותה אל
`~/.claude/skills/`.

## איך מפעילים
פתח את קלוד קוד וכתוב: "מה מצב הקמפיין שלי במטא בשבועיים האחרונים?".

## מה הסקיל עושה בפועל
הסקיל מוודא שיש חיבור לחשבון המודעות, מברר על איזה קמפיין ואיזה טווח תאריכים מדובר,
ומחזיר לך קודם כול שורה אחת: כמה הוצאת, כמה לידים נכנסו, וכמה עלה כל ליד. רק אם
תבקש, הוא ימשיך לפירוט לפי קבוצות מודעות ומודעות, ולהשוואה של הקמפיין לתקופה קודמת
שלו עצמו.

כשהנתונים מצדיקים המלצה, למשל קבוצת מודעות ששורפת תקציב בלי להביא לידים, הסקיל
מנסח את ההמלצה יחד עם המספרים שמאחוריה ומסיים בשאלת אישור. הוא מציג, אתה מחליט.

## מה הסקיל לא עושה, אף פעם
החיבור הוא לצפייה בלבד. הסקיל לא משנה תקציב, לא עוצר ולא מפעיל קמפיינים, ולא עורך
קהלים, יעדים או מודעות. גם לא אחרי שאישרת המלצה, וגם לא אם תבקש ממנו במפורש: במקרה
כזה הוא יסביר לך איפה לבצע את זה בעצמך בממשק. הוא גם לא כותב קבצים במחשב ולא מוציא
את הנתונים לאף אחד, כל התוצר מוצג בשיחה.
